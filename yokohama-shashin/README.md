# 横濱寫眞 — 令和の彩色室

写真の色と位置を取り出し、淡い顔料や発色する粒で描き直す、ブラウザー内で動く写真アプリです。

## 機能

- カラー原画を6色の淡い顔料へ変換
- 写真Aから配色を抽出し、写真Bの色の位置へ適用
- 円・四角・菱形・六角・輪・不規則な粒・RGBの点・RGBの縞で再構成
- 粒の密度・大きさ・発光・にじみ・位置のゆらぎ・背景を調整
- 部分彩色の筆、原画比較、PNG保存・共有

写真は端末内で処理します。画像をAPIへ送信する機能はありません。
通常写真の保存は長辺4,096pxまで、粒の描写は長辺2,048pxまでです。
モノクロ写真の元の色を推測する機能はありません。

## ローカルで開く

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。ビルドやパッケージのインストールは不要です。

## 検証

Node.jsを使える環境で実行してください。

```sh
node tests/engine.test.cjs
node tests/particles.test.cjs
```

配色抽出、Bの色と位置の保持、無彩色の保護、粒の8方式、密度と大きさの独立、RGBの粒数、背景と発光を検証します。
iPhone実機の操作・性能は別途確認が必要です。

## 画像

同梱の写真はアプリの見本です。目標として表示するAI彩色画像は、アプリの自動処理結果ではありません。
ブラウン管やフィルム粒子の物理シミュレーションではなく、形と発色を探索する実験です。
